Quick troubleshooting commands

Permission denied writing results	[sudo chown -R $USER:$USER results]

Old topology or errors on start	[sudo mn -c]

Not sure which controller is running	[Look at its first lines for mode=baseline or mode=dynamic, or ps aux | grep ryu-manager]

Kill a stuck controller	[pkill -f ryu-manager]

A client or server printed nothing	[sh cat /tmp/h1.out (or /tmp/srv.out) at the Mininet prompt]

Port number check	[sh ovs-ofctl -O OpenFlow13 show s1 (s1-eth6 should be port 6)]

Queue setup check	[sh ovs-vsctl list qos and sh tc -s class show dev s1-eth6]
